# Sequence Diagram: Аренда автомобиля

```mermaid
sequenceDiagram
    autonumber
    participant К as Клиент
    participant П as Приложение
    participant С as Система
    participant Т as Телеметрия
    participant Пл as Платёжная

    К->>П: Выбирает авто и бронирует
    П->>С: Проверить клиента
    С-->>П: Результат проверки

    alt Есть задолженность
        П-->>К: Аренда заблокирована
    else Задолженности нет
        П->>Т: Открыть автомобиль
        Т-->>П: Авто открыто
        П-->>К: Доступ разрешён
        К->>П: Завершает поездку
        П->>С: Рассчитать стоимость
        С-->>П: Стоимость рассчитана
        П->>Пл: Списать средства
        Пл-->>П: Списание успешно
        П-->>К: Уведомление об оплате
        П-->>К: Чек отправлен
    end
